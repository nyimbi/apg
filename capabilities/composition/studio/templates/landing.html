How It Works

From business intent to running code in four steps.

1

Describe your domain in APG

Write a .apg file describing capabilities, entities, workflows, governance rules, and UI screens. No boilerplate.

2

Compile to Python

The APG compiler generates service.py, models.py, api.py, views.py, migration SQL, tests, and OpenAPI spec.

3

Compose with other capabilities

Declare uses: [nats, vault, fintech_frd] and the composition engine wires adapters, event routing, and OPA policies automatically.

4

Deploy anywhere

Helm chart for Kubernetes, Docker Compose for local dev. Temporal + NATS + OPA start with docker compose up.
