# F&B User Guide

## Overview

The F&B Management capability (hos_fdb) provides a full point-of-sale system for restaurant operations with table management, kitchen display integration, menu engineering analytics, recipe costing, and ingredient inventory control.

## Key Features

- **Menu Engineering**: BCG-style Stars/Plowhorses/Puzzles/Dogs classification based on order count and gross margin.
- **POS Flow**: Seat guests → create order → send to kitchen → mark ready → settle bill.
- **Kitchen Display**: Kitchen tickets automatically created when orders are sent to kitchen.
- **Recipe Costing**: Define ingredients per dish; cost propagates to menu item and margin calculations.
- **Inventory**: Track ingredient stock levels with reorder alerts and adjustment transactions.
- **Tax**: 16% VAT applied automatically to all orders (configurable).

## Quick Start

1. Create tables and menu items.
2. Seat guests at a table.
3. Create an order with items from the menu.
4. Send order to kitchen.
5. Chef marks ticket complete when food is ready.
6. Settle the bill with payment method.
