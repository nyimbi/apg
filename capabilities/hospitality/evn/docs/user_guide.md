# EVN User Guide

## Overview

The Events & Venue Management capability (hos_evn) handles the complete event lifecycle from initial enquiry through contract, BEO generation, catering coordination, AV management, and final settlement.

## Key Concepts

- **Venues**: Physical spaces (ballrooms, conference rooms, outdoor areas) with capacity, AV, and catering configurations.
- **Event Bookings**: Client requests linked to venues with cost estimates computed automatically.
- **BEO (Banquet Event Order)**: The operational document sent to all departments detailing menu, setup, AV, and timing.
- **Contracts**: Formal agreements with deposit schedules and cancellation policies.
- **Payments**: Track deposit, interim, and final payments against event total.

## Workflow

1. Create venues with capacity and pricing.
2. Receive event enquiry → create event booking (tentative status).
3. Issue contract → client signs → booking confirmed with deposit.
4. Generate BEO with menu, AV, and setup details → finalise.
5. Record payments as they arrive.
6. Day of event: update to completed status.
