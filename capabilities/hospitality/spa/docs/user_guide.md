# SPA User Guide

## Overview

The Spa & Activities Management capability (hos_spa) manages the full spa operation: treatment catalogue, therapist rostering, appointment booking with automatic conflict detection, membership benefits, and retail product sales.

## Key Features

- **Auto-Assignment**: If no therapist is specified when booking, the system finds the first available therapist for the timeslot.
- **Conflict Detection**: Appointment creation validates no therapist double-booking.
- **Membership Discounts**: Linked membership discount percentages auto-apply at booking time.
- **Therapist Utilisation**: Reports percentage of 8-hour workday utilised per therapist.
- **Retail POS**: Track product inventory and sales alongside treatment revenue.

## Workflow

1. Create treatments (massage, facial, etc.) with duration and pricing.
2. Register therapists with specialisations.
3. Book appointments — specify therapist or let system auto-assign.
4. Complete appointment and record payment.
5. Issue memberships to repeat guests for discounts and bundled treatments.
