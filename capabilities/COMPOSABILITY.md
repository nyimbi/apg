### Rationale

Orphaned provides are not bugs. The PROVIDES list functions as a service advertisement.
Consumers bind to specific service names at integration time rather than declaring
hard requires edges. Hard requires is reserved for capabilities that must be deployed
before the declaring capability can start up.

## Circular Dependencies (detected and resolved)

All 8 dependency cycles were broken by removing the weaker directed edge from each cycle.
The general principle: remove the edge from the more capable/higher-level capability back
to the more foundational one.

| Cycle | Resolution |
|-------|-----------|
| `auth ↔ keym` | Removed `auth` from keym REQUIRES. keym (crypto primitives) is foundational; auth builds on it. keym uses audl+mten for its own governance. |
| `auth ↔ secu` | Removed `secu` from auth REQUIRES. auth is the identity/session layer; secu (security posture) builds on auth, not vice versa. |
| `accs ↔ them` | Removed `accs` from them REQUIRES. Theme management does not depend on accessibility tooling; accs consumes theme tokens. |
| `grc_doc ↔ grc_pol` | Removed `grc_doc` from grc_pol REQUIRES. Policies can reference documents logically but the policy engine does not require the document repository at runtime. |
| `composition_registry ↔ composition_access/config/events` | Removed `composition_registry` from composition_access, composition_config, and composition_events REQUIRES. The registry depends on those three; they do not need to know about the registry to function. |
| `composition_events ↔ composition_access` | Removed `composition_access` from composition_events REQUIRES. The event bus is a lower-level primitive; access control builds on it. |
| `composition_config ↔ composition_access` | Removed `composition_config` from composition_access REQUIRES. Access control is a lower-level primitive; config management builds on it. |
| `kngr ↔ onto` | Removed `kngr` from onto REQUIRES. Ontology (vocabulary/taxonomy) is foundational; the knowledge graph builds on ontology. |
