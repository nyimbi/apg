# CONS Capability Packet

This file is kept for compatibility with package tooling and older capability
indexes. The current CONS packet is defined in:

- `README.md` for usage and composition guidance.
- `SPECIFICATION.md` for functional and non-functional requirements.
- `PLAN.md` for the implementation and verification plan.

CONS is the APG Consent and Privacy Management capability. It provides
tenant-aware privacy notices, purposes, consent events, preference profiles,
privacy requests, consent-gated processing decisions, first-class AI privacy
agents, deterministic guardrails, Bytewax lifecycle-stream metadata,
composable API helpers, UI view models, theme tokens, and audit evidence.
