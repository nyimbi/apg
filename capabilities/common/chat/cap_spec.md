# Chat and Messaging Capability Specification

The active CHAT specification is maintained in `SPECIFICATION.md`.

Current scope includes first-class provider-neutral chat agents, Bytewax
lifecycle batch validation, deterministic guardrails, UI metadata, runtime
state, API helpers, view models, package evidence, and focused tests.

This file is kept as a compatibility pointer for tooling that still expects
`cap_spec.md` in each capability directory.
