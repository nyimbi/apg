# Process Mining — World Class Improvements

### I1. Temporal Drift Detection | Analytics | Process behaviour changes over time (seasonal, regulatory-driven, operational shifts); static models go stale. Industry leaders (Celonis, Disco) surface model drift automatically. | Sliding-window DFG diff: compare DFGs built over rolling time buckets, flag transitions whose frequency or duration deviates beyond a configurable sigma threshold. | Celonis Process Analytics temporal comparison

### I2. Resource Social Network Analysis | Analytics | Knowing who hands off work to whom reveals informal org structure and informal bottlenecks invisible in the activity graph. | Build a handover-of-work matrix from resource field: for each case where resource changes between events, record (r_from → r_to) weighted by frequency and avg handover delay. | Fluxicon Disco resource handover graph

### I3. Decision Mining on Branching Points | AI/ML | When the process splits (XOR gateways), the data attributes that predict which branch is taken are unknown. | At detected branching activities (multiple outgoing edges), extract per-case attribute vectors at the split point and train a lightweight decision tree to predict branch choice. Return rules as human-readable conditions. | ProM DecisionMiner plug-in

### I4. Root-Cause Analysis for Deviating Cases | Analytics | Surfacing deviating cases without explaining why is half the answer; operations teams need causal attributes. | For each deviating case, diff its attribute set against the conforming majority using Fisher exact test per attribute. Return sorted list of (attribute, p-value, effect-size) as deviation drivers. | Celonis Execution Management System root-cause view

### I5. SLA / KPI Breach Alerting | Compliance | Regulatory SLAs (e.g. payment settlement T+2, loan approval 5-day) must be monitored continuously. | Accept per-event-log SLA rules (activity, max_duration_s). On each ingest batch, scan running cases; emit `sla_breach` events and return breach summaries per rule with affected case IDs. | Signavio Process Intelligence SLA monitoring

### I6. Inductive Process Tree Discovery | Algorithms | Alpha miner produces non-sound models on real logs. Inductive Miner guarantees a sound block-structured process tree that converts to a valid BPMN. | Implement divide-and-conquer inductive miner: detect exclusive cuts, sequence cuts, parallel cuts, and loop cuts recursively on the DFG. Return structured process tree alongside flat DFG. | ProM InductiveMiner, PM4Py inductive_miner

### I7. Case Attribute Enrichment and Segmentation | Data | Events alone are insufficient; business outcomes (revenue, risk score) live on the case object, not events. | Accept arbitrary case-level attributes alongside events. Index by case_id. Support segment-by: re-run variant/bottleneck analysis scoped to a user-defined attribute filter (e.g. region=APAC, amount>10000). | IBM Process Mining attribute overlay

### I8. Predictive Completion Time | AI/ML | Knowing remaining cycle time for in-flight cases enables proactive intervention. | For each open case (no end activity seen), compute expected remaining time: look up the empirical distribution of total_duration for cases that followed the same partial trace prefix; return percentile bands (p50, p75, p95). | Celonis Action Engine predicted completion

### I9. Automated Happy-Path Extraction and Benchmark | Quality | The happy path is the intended flow; deviations from it represent rework, waste, or risk. Quantifying the gap is the core process improvement metric. | From variant analysis, mark the top-frequency variant as the happy path; compute per-case "happy path alignment score" (Levenshtein edit distance to happy path / max(len_actual, len_happy)). Return distribution of alignment scores. | Minit process benchmarking

### I10. Multi-Log Process Comparison | Analytics | Comparing the same process across regions, products, or periods answers "why does site A outperform site B?" | Accept two log IDs; build DFGs for each; compute symmetric difference of edges, Jaccard similarity of activity sets, and KS-test on per-edge duration distributions. Return ranked list of structural divergences. | Celonis multi-process benchmarking, Fluxicon comparative analysis

### I11. Object-Centric Process Mining (OCPM) | Advanced | Single-case-id models miss multi-object processes (order→items→payments). OCPM is the state of the art. | Accept events tagged with multiple object IDs (e.g. order_id + item_id). Build per-object-type DFGs and an object interaction graph. Detect convergence/divergence arcs between object types. | OC-PM by Ghahfarokhi et al., PM4Py ocpm module

### I12. Process Cost Analysis with Decimal Precision | Finance | Throughput time is a proxy; actual cost (resource hourly rate × time) enables ROI calculation for improvement initiatives. | Accept resource rate table (resource_id → hourly_rate Decimal). For each transition, compute cost = duration_h × rate. Aggregate per-activity, per-variant, and process-wide. All monetary values in Decimal. | Celonis financial impact layer, SAP Signavio cost overlay

### I13. Interactive Filtering with Dotted-Notation Attribute Paths | UX | Deep nested event attributes (e.g. metadata.customer.tier) are common in NATS payloads; flat key matching silently drops them. | Implement JSONPath-lite dot-notation extractor for case_id_field, activity_field, timestamp_field. Support e.g. "data.order.status" as field path. Applied at ingest time. | Axon Ivy process record attribute mapping

### I14. Process Model Merging / Overlay | Collaboration | Multiple teams discover models independently; a merged view shows where processes diverge vs converge without losing individual model provenance. | Accept two model IDs; compute union DFG (merged nodes, summed frequencies), intersection DFG (shared edges only), and difference set. Tag each edge with source model(s). | Celonis model versioning, ProM model merging

### I15. Streaming Conformance via NATS JetStream Consumer | Integration | Batch-mode conformance misses SLA breaches until the next run; continuous conformance catches deviations in near-real-time. | Maintain per-case running trace state. On each new event, extend the running trace and re-evaluate conformance against the bound model. Emit `conformance_deviation` NATS event on first detected deviation per case. Return currently deviating case count and sample. | Celonis Process Analytics streaming, Minit live process monitoring
