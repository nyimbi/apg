# SCRP Capability Packet

This file is kept for compatibility with package tooling and older capability
indexes. The current SCRP packet is defined in:

- `README.md` for usage and composition guidance.
- `SPECIFICATION.md` for functional and non-functional requirements.
- `PLAN.md` for the implementation and verification plan.

SCRP is the APG Scraper/Data Harvesting capability. It provides tenant-aware
source registration, extractor profiles, harvest jobs, guarded harvest runs,
result batches, pipeline handoff metadata, first-class AI harvest agents,
deterministic guardrails, Bytewax lifecycle-stream metadata, composable API
helpers, UI view models, theme tokens, and audit evidence.
