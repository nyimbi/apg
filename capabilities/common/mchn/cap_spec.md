# MCHN Capability Specification Pointer

`SPECIFICATION.md` is the normative capability specification for the MCHN
packet. This compatibility file remains for older tooling that discovers
capability packages through `cap_spec.md`.

Use these local artifacts together:

- `SPECIFICATION.md` for required behavior, rules, UI, theme, stream, and
  acceptance criteria.
- `PLAN.md` for the implementation and review packet.
- `README.md` for usage, composition, agents, and focused verification.
- `capability_contract.py` for executable configuration, rules, routes,
  theme, and Bytewax stream metadata.
