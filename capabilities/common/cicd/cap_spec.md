# CICD Capability Packet

This file is kept for compatibility with package tooling and older capability
indexes. The current CICD packet is defined in:

- `README.md` for usage and composition guidance.
- `SPECIFICATION.md` for functional and non-functional requirements.
- `PLAN.md` for the implementation and verification plan.

CICD is the APG Continuous Integration and Delivery capability. It provides
tenant-aware pipeline definitions, build runs, artifact metadata, quality gate
evidence, release promotions, first-class AI delivery agents, deterministic
guardrails, Bytewax lifecycle-stream metadata, composable API helpers, UI view
models, theme tokens, and audit evidence.
