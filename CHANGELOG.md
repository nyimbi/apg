# Changelog

## v0.1.0

- Wave A: generated-app security hardening with password hashing, login throttling, session fixation defense, request limits, secure API-key comparison, and graceful 404/500 handling.
- Wave B: operations baseline with structured JSON logging, request ID propagation, liveness/readiness endpoints, and Prometheus metrics.
- Wave C: HTTP efficiency with gzip compression, cache-control headers, ETags, and conditional GET support.
- Wave D: accessibility and UI hardening with table a11y, density controls, CSP nonce handling, and ARIA live status support.
- Wave E: API completeness with OpenAPI 3.1 output, API docs, pagination, filtering, sorting, and CSV export.
- Wave F: production hardening with startup validation, audit logging, rate limiting, and JSON content-type guards.
- Wave G: generated UI polish with dark mode, mobile layout behavior, and print styling.
- Wave H: compiler diagnostics with line/column reporting, suggestions, duplicate validation, and clearer error output.
- Wave I: database lifecycle patterns with timestamps, soft deletes, auto-migration, bulk operations, and lifecycle metadata.
- Wave J: outbound webhooks with event payloads, HMAC signing, and isolated delivery failures.
- Wave K: FTS5 full-text search and generated pytest scaffolding for compiled apps.
- Wave L: data governance with column ACL filtering, row ownership, and field-diff audit logging.
- Wave M: DSL relationships for `has_many` and `belongs_to` modeling with nested REST endpoints.
- Wave N: enum types and field validation rules including length, email, and pattern constraints.
- Wave O: file upload fields and SMTP-backed email notifications.
- Wave P: VS Code extension support with syntax, snippets, and language configuration.
- Wave Q: multi-tenancy and i18n scaffolding.
- Wave R: in-process job queue and computed fields.
- Wave S: LSP server support for completion, hover, diagnostics, and go-to-definition.
- Wave T: CLI excellence with `init`, `doctor`, `watch`, `serve`, and Docker `export`.
- Wave U: Python package metadata, editable install support, PyPI build scaffold, Makefile targets, changelog, and version file.
