# Local Reference Documents

Use this directory for copied local reference material such as PDFs, DOCX files,
spreadsheets, and slide decks that help APG development but should not be
tracked as source documentation.

Guidelines:

- Keep canonical APG guides as Markdown under `docs/`.
- Keep historical APG planning artifacts under `docs/archive/`.
- Put large copied reference files here instead of the repository root or the
  top-level `docs/` directory.
- Do not commit copied reference binaries unless a specific review requires
  them.
