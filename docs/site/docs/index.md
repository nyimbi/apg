# APG — App Platform Generator

**APG** is a domain-specific language (DSL) compiler that turns concise schema definitions into
production-ready Flask web applications — complete with a REST API, authentication, audit logging,
metrics, and a dark-mode UI — in a single compile step.

---

## 30-second example

```apg
module crm version 1.0.0 {
    description: "Simple CRM";
}

table Contact {
    name:    str;
    email:   str;
    phone:   str?;
    company: str | None;
    active:  bool = true;
}

app CRM {
    description: "Contact manager";
    routes: ["/contacts"];
}
```

```bash
apg compile crm.apg --output out/
python out/app.py
```

That's it. You now have a running Flask service with:

- `GET /contacts` — paginated list with filtering and CSV export
- `POST /contacts` — create with JSON validation
- `GET /contacts/<id>` — fetch one
- `PUT /contacts/<id>` — replace
- `PATCH /contacts/<id>` — partial update
- `DELETE /contacts/<id>` — soft-delete
- `GET /livez` and `GET /readyz` — liveness and readiness probes
- `GET /metrics` — Prometheus-format metrics
- `GET /openapi.json` — OpenAPI 3 schema

## Why APG?

| Problem | APG answer |
|---------|------------|
| CRUD boilerplate takes days | Compile in seconds |
| Auth is always re-invented | Baked-in session + JWT + API-key auth |
| Security forgotten at first | CSP, CSRF, rate-limiting, audit log generated by default |
| "Works on my machine" | Single-file `app.py` — zero hidden deps |
| OpenAPI as an afterthought | Generated automatically from the schema |

## Key features

- **All field types** — `str`, `int`, `float`, `decimal`, `bool`, `date`, `datetime`, `time`, `bytes`, `uuid`, `json`, `file`, collection types
- **Relationships** — `has_many`, `belongs_to`, `has_one`, and through-associations with nested REST endpoints
- **Validation** — `@email`, `@min_length`, `@max_length`, `@min`, `@max`, `@pattern`, `@optional`
- **Enums** — `enum ["a", "b", "c"]` inline or named
- **Computed fields** — server-side expressions derived at read time
- **Workflows** — state-machine step definitions with human tasks and guards
- **Webhooks** — HMAC-signed outbound webhooks with retry
- **Full-text search** — FTS5-backed search endpoints
- **Multi-tenancy** — tenant isolation scaffolding
- **i18n** — locale and theme scaffolding
- **VS Code extension** — syntax highlighting, snippets, and Language Server
